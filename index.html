O QUE É GIT?

Git é um sistema de controle de versão distribuído, gratuito e de código aberto, criado para gerenciar alterações em projetos de software com rapidez, segurança e eficiência.


Ele permite que desenvolvedores acompanhem versões do código, trabalhem em equipe simultaneamente e mantenham um histórico completo das modificações, sendo capaz de atender desde projetos pequenos até aplicações de grande escala.
